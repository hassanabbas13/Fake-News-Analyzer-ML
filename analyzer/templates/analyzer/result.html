{% extends "analyzer/base.html" %} {% comment %} result.html — one analysis, explained ===================================== Shows how the verdict was reached, and what it is worth. The rule that shapes this page: NO ARTICLE COUNTS OR ACCURACY FIGURES ARE TYPED HERE. They arrive through analysis.explanation, which analysis_engine.py builds from the model's own recorded numbers. A figure written into this template would survive the next retraining and quietly become a lie. That has already happened once in this project. The web-search block is kept visually separate from the verdict for the same reason. The verdict's percentage is measured on 3,160 articles with known answers. The web check is measured on nothing. Merging them would produce one confident-looking number with only half of it standing on evidence. Two template rules worth knowing before editing this file. The extends tag has to come first, ahead of even this comment, or the parser refuses the template. And a hash-style comment is single-line only — spread one over two lines and Django stops treating it as a comment and prints it into the page. Multi-line notes therefore use the comment tag, here and everywhere else in this directory. {% endcomment %} {% block title %}Result: {{ analysis.result_label }} — Fake News Analyzer{% endblock %} {% block nav_analyze %}active{% endblock %} {% block content %}
