{% load static %}{% comment %} base.html — the skeleton every page extends =========================================== Neo-brutalism: hard black borders, offset shadows, buttons that press down. The colours mean things — see the note at the top of static/analyzer/style.css before adding any. Bootstrap's stylesheet is gone. It was fighting the flat borders and hard shadows on every element, and the layouts here are small enough to write directly. Bootstrap ICONS stay: that is a font file, not a layout system, and the templates use `bi bi-*` throughout. Each page marks its own nav tab by filling one of the nav_* blocks with "active" — a plain string, so nothing has to be passed from views.py. Note the comment syntax. {# #} in Django is SINGLE-LINE ONLY: spread it over two lines and the template engine stops treating it as a comment and prints it into the page.
