{% extends "analyzer/base.html" %} {% comment %} analyze.html — the input page ============================= One textarea. First line is treated as the headline, the rest as the body — see views.analyze(), which splits on the first newline. The word counter is the only piece of logic on this page, and it exists because the server rejects input outside 25-400 words. Finding that out after submitting means losing your paste and the page you were reading it on. It reads its limits from data- attributes on the textarea (set in forms.py from input_check.py), so there is no second copy of the numbers to go stale. It advises, it never blocks. The counter runs on the browser's idea of a word; clean_news_content() runs on Python's. They agree on English prose, and where they might not, the server is the one that decides. {% endcomment %} {% block title %}Analyze News — Fake News Analyzer{% endblock %} {% block nav_analyze %}active{% endblock %} {% block content %}
